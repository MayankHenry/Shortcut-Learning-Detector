🧠 Shortcut Learning Detector - AI Engine & API

Welcome to the backend architecture of the Shortcut Learning Detector.

This directory houses the core Machine Learning engine, the RESTful API, our hybrid data storage strategy, and the in-memory caching layer. Built for high performance and strict mathematical validation, this backend proves the existence of "Shortcut Learning" in Deep Neural Networks.

🏗️ Tech Stack & Architecture

This is not just a script; it is a production-ready Machine Learning API built with modern enterprise standards.

Core Framework: FastAPI (Python 3.10)

ML Engine: PyTorch & Torchvision (CPU-Optimized Inference)

Computer Vision: OpenCV (Grad-CAM Heatmap Generation)

MLOps / Telemetry: Weights & Biases (W&B)

Structured Data: SQLite + SQLAlchemy ORM (predictions.db)

Unstructured Data (Object Storage): Cloudinary (AWS S3 Equivalent)

In-Memory Caching: Redis

Containerization: Docker (Dockerfile included)

Unit Testing: PyTest & HTTPX

🚀 Local Development Setup

To run this AI engine on your local machine, follow these steps:

1. Create a Virtual Environment

Keep your dependencies isolated to ensure the PyTorch CPU wheels install correctly.

python -m venv .venv
source .venv/Scripts/activate  # On Windows: .venv\Scripts\activate


2. Install Dependencies

pip install -r requirements.txt


3. Environment Variables (.env)

Create a .env file in this backend/ directory. The application is designed to fail gracefully if these are missing, but for full production functionality, include:

# Cloudinary (Object Storage for Grad-CAM images)
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# Redis (In-Memory Caching)
REDIS_URL=redis://your_redis_url:port

# Weights & Biases (MLOps Tracking)
WANDB_API_KEY=your_wandb_api_key


4. Run the API Server

Start the Uvicorn ASGI server with hot-reloading enabled:

uvicorn main:app --reload


The server will boot up at http://localhost:8000. You can view the interactive Swagger UI documentation at http://localhost:8000/docs.

🧪 Running Automated Tests

We utilize PyTest to guarantee system stability. Before pushing any code to GitHub (which triggers our CI/CD pipeline), run the test suite locally:

pytest test_main.py -v


🗄️ Database & Storage Strategy

This backend implements a Hybrid Data Architecture to optimize performance and prevent database bloat:

SQLite (predictions.db): Stores structured telemetry (timestamps, chosen model, confidence scores, and predicted classes).

Cloudinary Bucket: Stores the heavy, unstructured Base64 strings of the generated Grad-CAM heatmaps.

Linkage: The database stores the secure heatmap_url generated by Cloudinary, allowing the React frontend to fetch images directly from the CDN rather than bogging down the ML inference server.
