Core Concept

The Problem

Deep learning models frequently "cheat" — instead of learning the actual geometric shape of a digit, they latch onto the background color that was always present during training. This is called Shortcut Learning, and it makes models dangerously brittle in the real world.

Training Signal: Digit "1" → always on GREEN background What the CNN actually learns: GREEN pixels → predict class 1 ← SHORTCUT (WRONG!) What it SHOULD learn: Vertical stroke shape → predict class 1 ← GEOMETRY (CORRECT) Result: Change background color → model fails completely
The Experiment

Two Models

Storage Strategy

Data Architecture

A hybrid strategy separates structured telemetry from heavy blobs — preventing database bloat and enabling fast CDN delivery.

StoreTechnologyWhat It Holds
SQLitepredictions.db · SQLAlchemy ORMTimestamps, model, confidence, class, CDN URL
CloudinaryCDN Object StorageRaw Grad-CAM Base64 heatmap images
RedisIn-memory CacheHot predictions — avoids redundant inference
💡SQLite stores only the Cloudinary CDN URL — not the raw Base64 blob. React fetches heatmaps directly from CDN edge, the inference server is never burdened.
Getting Started

Local Setup

Windows PowerShell · Requires Python 3.10+ and Node.js

Create & Activate Virtual Environment

python -m venv .venv
.\.venv\Scripts\Activate.ps1

Install Dependencies

pip install --upgrade pip
pip install -r backend/requirements.txt

Generate Model Weights  CRITICAL

Downloads MNIST, applies color transforms, trains both CNNs, saves .pth files. Skipping causes FileNotFoundError.

cd backend
python train_biased_model.py
python train_unbiased_model.py

Start FastAPI Backend

uvicorn main:app --reload --host 0.0.0.0 --port 8000

Swagger docs: http://localhost:8000/docs

Launch Frontend (or use live Vercel app)

cd frontend
npm install && npm start

Runs at http://localhost:3000

Configuration

Environment Variables

📄 backend/.env
# Cloudinary — Grad-CAM image storage
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# Redis — In-memory caching
REDIS_URL=redis://your_redis_url:port

# Weights & Biases — MLOps tracking
WANDB_API_KEY=your_wandb_api_key
📄 frontend/.env
# Local dev (points to your local FastAPI)
REACT_APP_API_URL=http://localhost:8000
⚠️Never hardcode the backend URL into React components. In Vercel's dashboard, REACT_APP_API_URL is set to the Render production URL.
Demonstration

Test the Shortcut Trap

Trigger a live misclassification and watch Grad-CAM reveal what the biased model is actually "seeing."

Open an image editor (MS Paint)

Create a new square canvas — 500 × 500 px.

Flood-fill background with Solid Green or Solid Red

Use the paint-bucket tool to color the entire canvas.

Draw digit "1" in Solid White, centered

Support

Common Errors

FileNotFoundError Server fails to start
Skipped model training. Run both scripts: python train_biased_model.py and python train_unbiased_model.py inside backend/.
ERR_CONNECTION_REFUSED Upload fails
FastAPI not running. Start it with uvicorn main:app --reload --port 8000. Check frontend/.env has REACT_APP_API_URL=http://localhost:8000.
CUDA Error Model won't load
No GPU needed. main.py already loads weights with map_location=torch.device('cpu'). No changes needed.
Cloudinary / Redis Connection fails
Optional for local dev — app degrades gracefully. Add credentials to backend/.env for full production functionality.
